## 🧑‍💻 About me

- 🎙️ **MTS – Software at [Retape AI](https://www.ycombinator.com/companies/retape) (YC W23)**: I own the voice and text customer-support agents end to end. I moved them from a cascaded STT → LLM → TTS pipeline to a full-duplex voice model on [LiveKit](https://livekit.io), added a judge model for every tool call that moves money, and added keypad (DTMF) verification after call reviews showed people typing. Transfers to human agents are down about 40%.
- 🏢 Previously a **Software Engineer at [UKG](https://www.ukg.com)**: I cut a search API's p95 latency by 80% by fixing N+1 queries, built RBAC and feature-flagged features, and worked on RAG ingestion for UKG's multi-agent AI assistant.
- 🎓 **B.Tech, Electronics Engineering, [IIT (BHU) Varanasi](https://iitbhu.ac.in)** ('25), where I was Convener of the Web Management Committee.
- ⚡ Interested in **real-time voice AI, LLM tool calling, LLM-as-judge guardrails and RAG**.
